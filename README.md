# base-de-datos
trabajo de bases de datos

julian-Roncxx

descripcion: understock tiene como finalidad el mejoramiento en el manejo de sistemas inventarios con fines de mejorar el sobresaturamiento de datos por sobrestock o falta de este mismo

usuario: cliente, proveedores , adminsitradores y superusuario.

reglas de negocio:

Asignación de domiciliarios: Cada pedido debe ser asignado a un domiciliario disponible para garantizar una entrega oportuna.
Gestión independiente de servicios: Los pedidos, domiciliarios y notificaciones deben gestionarse de manera independiente para evitar que una falla en un servicio afecte a los demás. Esto se relaciona con la propuesta de implementar microservicios.
Integración mediante APIs: El sistema debe permitir la integración con nuevos canales de venta mediante APIs o interfaces claramente definidas.


el proyecto es suficientemente grande gracias a su capacidad de adaptacion a largo plazo y su facilidad de mejora continua y debdio a sus cambios a nivel de arquitectura consideramos que este proyector es el mas adecuado para trabajar debido a que se encuentra atraves de microservicios 


el uso de IA se realizara con fines de organizacion a nivel de copdigo y docuemntacion de este mismo , usaremos iA como deepseek , claude entre otras.
